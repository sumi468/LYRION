# 同梱フォント

Google Fontsの公式リポジトリから取得したOxaniumとM PLUS 1の可変フォントを、利用文字にサブセット化したWOFF2です。OFL 1.1のライセンス・著作権表示を同梱しています。

- https://github.com/google/fonts/tree/main/ofl/oxanium
- https://github.com/google/fonts/tree/main/ofl/mplus1

英数字とUI内の日本語、ひらがな・カタカナを収録。未収録の文字はCSSのシステムフォントへフォールバックします。新しい日本語コンテンツを追加する際はサブセットを更新してください。
