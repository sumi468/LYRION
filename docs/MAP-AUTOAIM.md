# 星系マップとオートエイム — v0.9.0-dev.3

## 操作

- **M / MAP**、または一時停止画面の「星系マップ / テレポート」で開きます。目的地を選び、**ここへテレポート**を押すと移動します。Mでも閉じられます。目的地の選択だけでは移動しません。
- 惑星・衛星・恒星・小惑星帯・探査機に加え、**PORT LYRA / PAD 01**と**ASTERION STATION**を選べます。図は距離を圧縮した模式図です。衛星や施設は一覧から選択します。
- 料金・クールダウンはありません。地形とリングを避けた上空へ到着し、元の速度を解除して移動先の基準系に合わせます。PAD 01は地表400 m、通常の惑星は1.5 km、PRIMEは基地上空5 km、ASTERIONは接岸可能な誘導灯の手前です。
- 機内の通常飛行中のみ使用できます。着陸・降下中はG、接岸・離脱中はT、船外・地上活動中はHで機内飛行へ戻ってください。交戦中は使用できず、マップに理由を表示します。
- テレポートは位置と航行の一時状態だけを変更します。所持DATA・HP・エネルギー・時刻・スキャン・報酬フラグは直接変更しません。到着後の任務進行は、通常の到着判定や調査・報告の手順に従います。移動直後に保存します。

## オートエイム

- 初期ON。設定の**オートエイム**で切り替えられ、OFFも保存されます。旧設定を読み込む場合はONが初期値です。
- 正面25°、距離1300 m以内の敵を捕捉。捕捉後は30°まで追尾して目標の切り替わりを抑えます。敵と自機の相対速度から弾の到達点を予測します。
- HUDの**AUTO LOCK**と敵の枠で捕捉を表示します。左クリック / J / FIREを押したときだけ射撃します。自動射撃・威力増加・敵HPの減少・機体の瞬間旋回はありません。
- 撃破、射程外、後方、到達できない予測点、惑星による遮蔽、着陸などの安全状態、テレポートでロックを解除します。OFFでは従来の狭い照準補助に戻ります。

## 安定性

移動はデバッグ用の配置処理を流用せず、通常プレイから使う専用APIです。地形高さ・軸傾斜・点速度・ステーションの共有基準系を使い、移動前に他天体との重複を検査します。移動時には入力、照準、残弾、スキャン、カメラ追従を同期します。セーブの形式とキーはv5のままです。

オートエイムは既存の固定プールと再利用ベクトルを使い、敵ごとの新しい描画物や毎フレームのVector3生成を追加していません。移動先は既存の天体データを参照します。

## 検証

TypeScript、152件の単体テストが通過。移動の禁止状態、安全な高度・回転と速度の同期、オートエイムの角度・射程・遮蔽・目標維持・実弾命中・設定保存を含みます。

専用E2Eは55項目すべて通過、ページ・描画エラー0件。[実行記録](validation/map-aim.json)に結果を保存しています。NVIDIA GeForce RTX 4060 / Chrome 157でWebGL 2・WebGPUを実際に起動し、マップからの移動、全目的地への反復、PADへの着陸、EVA/交戦中の拒否、照準補正と画面内のAUTO LOCK、OFFの保存、タッチ縦横画面を確認しました。PCのマップ、捕捉中のHUD、スマホ縦横の画面も画像で確認しています。

既存の全E2Eも197項目と安定化監査13項目が通過しました。従来のタッチ操作、11天体・8ミッション、飛行・戦闘・着陸、接岸、EVA、6遠征、報酬、保存・再開、ミッションHUD、宇宙服の確認を含みます。今回のタッチMAP追加で一時停止ボタンの位置が変わったため、従来のCAM・一時停止の順番を保つ形に修正して再検証しています。
