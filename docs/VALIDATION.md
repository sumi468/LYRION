# LYRION v0.3.0 検証レポート

2026-10-23（日本時間）。元の v0.1.0 を引き継ぎ、ゲーム進行・描画・音・入力・配布起動を検証しました。元フォルダーは変更していません。

## 環境

- Windows / Node.js 24.20.0 / Chrome 155.0.8059.85 / Playwright 1.64.1。
- NVIDIA GeForce RTX 4060、VRAM 8GB、ドライバー610.88。
- WebGL 2、ANGLE / Direct3D 11。検出文字列:

```
ANGLE (NVIDIA, NVIDIA GeForce RTX 4060 (0x00002882) Direct3D11 vs_5_0 ps_5_0, D3D11)
```

`WEBGL_debug_renderer_info` でNVIDIAの実GPUを確認し、SwiftShader / ソフトウェアGLを検出した場合はGPUテストを失敗させています。

E2Eでは次の動作を検査しました。

- 起動、前進、視点切替、スキャン、報酬、強化、保存と復元、画質反映、一時停止と再開。
- 11天体すべてのスキャン、8ミッション完了、クリア画面、クリア後の11件の記録・報酬・強化の保存。
- 音声を操作前に作らず、開始操作後に音声波形が出ること。一時停止・サウンドOFF・音量0・終了時の破棄。
- 仮想スティック、ドラッグ視点、BOOST、SCAN、停止時の解除。横800×360・縦390×844の配置。
- 合成PointerEventに加え、Chromiumの入力経路に2本の指を送り、前進とBOOSTの同時操作・解放を検査。
- 画質12回切替でGeometry **18→18**、Texture **15→15**。完了を待ってから測定。
- `WEBGL_lose_context` による実コンテキストの喪失・復帰後、テクスチャを作り直して描画。
- 実際のフレームループに38msの負荷を入れ、Auto画質が **L3→L0** へ降下。低速端末を模擬した制御テストであり、RTX 4060で自然に負荷が不足したことを意味しません。
- A/Dで停止位置から平行移動せずバンク旋回。前進しながらの右旋回、入力解放での復元、30 / 60 / 144Hzの角度整合を確認。
- Oxanium / M PLUS 1の実ロード、効果音0でBGM単独の波形、新船体17メッシュを確認。
- コンソール・ページエラー0件。

進行E2Eは移動をデバッグAPIで行い、スキャン済み状態や報酬は書き換えていません。長距離をすべて手動操縦するテストではありません。

## GPU性能

1920×1080、deviceScaleFactor=1、ヘッドレスChrome。Low / Medium / High / Autoを、それぞれ出発地点、タラッサ（表面距離400u）、アウレリオン（800u）で測定。各場面は2秒ウォームアップしてから6秒間の通常rAFループを収集しました。

Low / Mediumでは内部解像度も画質に従って下がります。Autoの内部解像度と段階は測定中に変化し、今回の環境ではL3からL5へ上がりました。

| Low | タラッサ近傍 | 1248×702 | 172.8 | 6.1 | 0.058 | 0.197 |
| Low | アウレリオン近傍 | 1248×702 | 171.8 | 6.1 | 0.077 | 0.223 |

この環境ではrAFが約171〜173回/秒で動きました。**ディスプレイ上の表示FPSとは異なります。** 60Hzの表示では表示上限が変わります。3場面・短時間・1台の結果を全環境の性能保証には使えません。

GPU描画時間は `EXT_disjoint_timer_query_webgl2` の40サンプルです。JS＋GPU完了待ちはシミュレーションを止めて描画し、各回 `gl.finish()` で完了を待った40サンプルです。rAF測定とは別に採っています。画面の合成・ディスプレイ出力・音声の時間を含まず、タイマー精度の影響もあります。

メニュー到達までの所要時間はLow 1.879秒、Medium 0.658秒、High 0.898秒、Auto 0.657秒でした。Lowから順に同じブラウザで実行したため、OS・ドライバーのキャッシュが影響します。画質別のコールド起動比較ではありません。

## 連続飛行とリソース

1080p・Highで **120.8秒**。6か所を繰り返し訪れ、実際のキー入力で推進／ブースト、左旋回、ブレーキを実行しました。サンプル20件すべてでプレイ継続、座標は有限、致命的画面なし、コンソール・ページエラー0件でした。

Geometryは29、Textureは16で全サンプル一定。今回の2分間で継続的な増加は見つかりませんでした。これはGPUリソースの個数の確認であり、GPUメモリーのバイト単位計測や数時間のリーク検査ではありません。

## 未検証・実用上の範囲
