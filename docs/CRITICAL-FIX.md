# LYRION v0.7.1 — Critical Implementation Fix

2026-10-28（日本時間）。前回の未コミット実装を再利用し、正式なホームワールド、利用できるMISSION CONTROL、独立した6遠征を統合しました。本番デプロイは実行していません。

## 現状調査と原因

- 作業開始時は `main`。ローカルHEADと取得したGitHub `origin/main` はともに `5246b1d293ca3b12feada8b3331b04db6d03596d`、コミットの先行・遅延は0でした。
- GitHub mainはv0.6.0。ローカルには未コミットの母星・基地・6遠征・EVA実装が存在し、公開版へ反映されていませんでした。これらを破棄せず再利用しています。
- ローカル母星IDは`prime`でした。今回指定の`lyrion-prime`へ変更し、移行を追加しました。基地はTabのターゲット選択へ接続されていなかったため、追加しました。
- 公開中のJavaScriptとCSSを取得し、保存していたv0.6 ZIPの対応ファイルとSHA-256で照合。3資産すべてが完全一致しました。公開URLの`build-info.json`は404です。
- 既存公開記録のコミットは5246b1d（実装ソース23bf255）。現在のVercelデプロイSHAの直接取得はチーム権限403で確認できていません。公開資産の一致から旧v0.6であることは確認済みです。[照合記録](validation/public-version-inspection.json)

## 修正した機能

1. **LYRION PRIME** — 正式ID `lyrion-prime`、居住する地球型ホームワールド。海・大陸・雲・大気・自転・昼夜・夜側の居住灯を持ち、THALASSAと別の天体です。
2. **新規開始** — PRIMEを正面に見るASTERION近傍の安全な位置。基地の点速度と適切な姿勢を継承します。旧セーブの位置・姿勢は維持します。
3. **ホーム基地** — Tabで選択、名前・距離・相対速度・誘導マーカー、接岸・自動離脱、修理・補給・強化、EVA、成果の受領。
4. **MISSION CONTROL** — メインメニュー・一時停止・B / 基地から開けます。6遠征、説明、各目標、状態、報酬、解放状況、調査記録を表示。旧セーブでも一覧は消えません。「基地へ誘導」は実際の位置を変えずに帰還先を選択します。
5. **受注と進行** — 受注・報告は接岸中に実行。出航、指定座標への到達、速度保持、船外へ出る、範囲内で作業、船へ戻るなどの実際の行動で順次進行します。UIだけで完了せず、調査と報告の報酬は一度だけです。
6. **保存** — セーブv4、保存キー継続。v1/v2の位置・探索・旧ミッション・DATA・強化・戦闘記録を維持。未公開v3の`prime`と遠征記録も移行。船外セーブは成果を残して機内へ安全復帰します。

LUMENの着陸は今回の指定に合わせて任意とし、従来の着陸・離陸機能を維持しています。旧11天体の図鑑と8つの`missionIndex`は変更していません。

## プレイヤーの確認手順

1. 配布ZIPを展開し`START.cmd`を実行します。メニューの **BUILD 0.7.1** とソース識別子で修正版を確認できます。
2. 「新しい探査を開始」。母星と基地が正面に見えます。T / DOCKで接岸してください。
3. B / 基地→MISSION CONTROL→「最初の出発」の「受注して追跡」→操縦へ戻る。
4. T / DOCKで離脱し、航行マーカーを追ってください。到達後はXで相対速度を落とします。帰還・接岸後に「遠征成果を報告」で30 DATAを受け取ります。
5. 「軌道上の点検」を受注。H / EVAで船外へ出て、2設備へ移動し、3.6u以内でE / 調査。Y / 帰還またはハッチ付近のH / 搭乗で戻ります。

PCはB:MISSION CONTROL、Tab:ターゲット、T:接岸・離脱、H:船外・搭乗、E:船外調査、Y:帰還支援。タッチは基地・DOCK・EVA・調査・搭乗・帰還ボタン、左スティック、上下、ドラッグ視点を使用します。基地から離れていてもメニューで現在の遠征を確認できます。
