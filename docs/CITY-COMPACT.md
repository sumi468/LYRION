# PORT LYRAと小型星系 — v0.9.0-dev.4

惑星と航路を小さく戻し、街は探索できる都市へ拡張しました。以前の巨大な星系を再び一律拡大する処理はありません。1 u=1 mのまま、宇宙船・宇宙服・建物の寸法を維持しています。

## 遊び方

- 惑星間は通常のW / Fで飛べます。Fは長押しでブーストし、障害物から離れると巡航へ切り替わります。Xで減速。M / MAPの惑星間テレポートも使えます。
- PORT LYRAへはMでPAD 01を選び、上空400 mからGで着陸、Hで降機します。
- 地上でM / MAPを開くと**市内シャトル**。宇宙港、行政・商業センター、公園、住宅街、研究キャンパス、物流港の6区画を無料移動できます。停留所の近くではEでも開けます。
- 市庁舎前で任務の受注・成果報告、研究区でアーカイブとアップグレード、物流港で駐機中のLX-07へ遠隔補給ができます。従来の宇宙港の端末も使用できます。
- 船は宇宙港に駐機したまま。シャトルで宇宙港へ戻り、ハッチからHで搭乗、Gで離陸してください。
- FIRST STEPSの軌道帰還目標は高度**3.5 km**へ短縮。報酬150 DATAは一度だけ受け取れます。

## 街と惑星の変更

| 項目 | 変更後 |
| --- | --- |
| 建物 | 24棟から240棟、住宅・研究・行政商業・物流の街区 |
| 市街地 | 東西約2 km、南北約1.5 km。58階建てのランドマーク、大通り、公園、停留所 |
| 街の動き | 14台の路面シャトル車両、64人の通行人。軽量な決定的アニメーション |
| PRIME | 半径3,100 kmから5 kmへ縮小 |
| CINDRA | 半径1,200 kmから1.2 kmへ縮小 |
| 天体の軌道 | v5の約1/1000。ステーションはPRIME上空5 km |
| 移動の例 | CINDRA → THALASSA、通常推進・Fのブーストで約38秒（テスト操縦、テレポートなし） |

地形を接平面へ合わせ、道路・歩行・外壁の衝突を同じ市街地データから計算します。建物と道路の重なり、停留所が壁の中にないこともテストします。市街地上空への着陸は禁止し、PAD 01または開けた陸地を案内します。

## 実際に見つけた問題と修正

- 星系の1万倍拡大により、通常飛行の移動と地上任務の120 km上昇が長時間化していました。天体・軌道と帰還目標を小型星系向けに再設定しました。
- 小さな球に広い平面の道路を置くと、建物が浮き、地面と靴底がずれます。街の地形を実際の接平面へ合わせ、歩行床と衝突判定も拡張しました。
- 雲の殻が低く、都市の外縁や高層部と交差していました。雲を上げ、大気・空・照明の高度による切り替えも小型惑星に合わせました。
- WebGPUで都市上空が白く覆われる問題を実画面で再現。雲を非表示にすると解消し、GPUから読んだ旧テクスチャの平均アルファは約90%でした。雲量のしきい値が逆だったため、WebGLと同じ`1 - coverage`へ修正。未生成の雲も描画しません。
- 星系変更時に基地の駐機位置まで縮めると、元の場所と機体の向きが失われます。基地・ステーションの位置、回転、角速度、点速度を使って移行し、機材に対するメートル単位の距離を維持します。

## 保存と性能

セーブv6はv1〜v5を読み込みます。v5の原文は最初の上書き前に`lyrion.save.before-compact-v6`へ一度だけ退避。DATA、調査、ミッション、強化、報酬フラグを維持し、地上から再開すると安全に駐機船へ戻ります。実際の旧公開版で作ったDATA 55のセーブも移行テストに含めています。

街の建物は材質ごとに結合し、交通・通行人はInstancedMeshを使用。窓や街灯ごとに光源を作りません。詳細表示は既存の画質設定へ連動し、遠ざかった地形のGPUリソースを破棄します。

最終テストの詳細は[都市・移動の記録](validation/city-scale.json)、[街・着陸・性能の記録](validation/settlement-quality.json)、[地上任務](validation/surface-expedition.json)を参照してください。GPU測定はRTX 4060・Chrome・Mediumでのヘッドレスブラウザ実時間測定です。モニターの表示FPSとは異なります。

TypeScriptチェック、162件の単体テストとビルドが通過。都市E2Eは42項目、着陸・歩行・街の性能は57項目、FIRST STEPSの実作業・軌道帰還は27項目、マップ・オートエイムは55項目すべて通過しました。端末の徒歩接近とE操作、全区画のシャトル、旧公開セーブ、保存再開、スマホのMAP操作も含みます。

既存の全E2Eも197項目と安定化監査13項目が通過。8ミッション・6遠征、飛行、戦闘、着陸、接岸、EVA、調査、報酬、保存再開、PC・タッチ操作、宇宙服の5方向の実画面を再確認しました。

都市の実時間測定はWebGL 2で約176 FPS・174描画、WebGPUで約168 FPS・177描画。どちらも約84〜87万三角形です。地上と宇宙を4往復する既存試験でも、地形リソースを解放し、ジオメトリ・テクスチャ数が増え続けないことを確認しました。
