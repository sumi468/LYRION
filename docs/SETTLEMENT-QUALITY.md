## 遊び方と案内

1. BのMISSION CONTROLから「PRIME地上基地へ誘導」を選び、**PAD 01 / PORT LYRA**の青いマーカーへ飛びます。
2. **F / BOOSTは長押し**。周囲の地形・ステーション・機材から5km以上離れ、交戦中でなければ距離に応じて長距離巡航へ移行します。近距離は通常のブーストです。HUDに現在のモード・巡航倍率・上限速度・毎秒の消費・残り秒数を表示します。
3. 接近時はFを離し、**X / BRAKEで減速**。倍率が下がっても慣性があるため、早めに制動します。燃料枯渇時はENERGYが15%に戻るまで再充電します。
4. 着陸案内に**高度450m以下、地表速度100m/s以下、平坦で障害物なし**がそろうと緑になります。G / LANDで降下、もう一度Gで中止します。PAD 01の中央8mが目安です。市街地・建物・海面には着陸できず、理由を表示します。平坦な野外への着陸と他の固体天体への探索も維持します。
5. 着陸後はHで降機。**歩行2.3m/s、Shift / 速歩ボタンの長押しで3.5m/s**。速歩のエネルギー消費はありません。地上の歩行と船外の無重力操作を混同しない表示にしました。
6. 港の西側にMISSION CONTROL、北西にSURFACE LAB、東側にSERVICE BAYとCOMMS ARRAYがあります。既存の地質調査地点・報告・搭乗・軌道帰還の進行は維持します。

## 港町のデザイン

- 小さな前哨基地の北側に**24棟**の市街地を配置。行政・医療・交通・居住・研究・物流の地区と、高さの異なる建物で街の構成を作りました。
- 道路・歩道・横断表示・入口の前庭・バルコニー・屋上機器・街灯・植栽・ベンチ・貨物・給水設備・太陽光発電・停車した作業車を配置しました。港にはPAD 01の番号、案内板、進入灯があります。
- 建物や主要設備には外壁の衝突判定があります。港のデッキ・道路・歩道では足の接地面も合わせ、地面に埋まらないようにしています。
- 既存の太陽光に、PRIMEの空と地面からの拡散光を追加。布・外装・窓・舗装の質感を同じ照明で確認しました。
- 独自に作成したローカルの窓・舗装・看板テクスチャを使用。外部配信・外部モデル・追加の利用料はありません。
- 材質ごとに静的形状を結合。窓や街灯ごとにライトを作らず、細部を画質別の距離で非表示にします。地形のチャンク予算は増やしていません。

建物は外観と外壁です。内装、住民AI、交通シミュレーション、別の星への都市追加は実装していません。機能を持つ端末と、その周りに生活・物流を感じる外装を整える変更です。

### GPUと描画負荷

1280×720のビューポート、Medium、ヘッドレスChrome。各場面1.5秒のウォームアップ後、3秒間のrAF間隔を測定しました。市街地は**3.5m/sで速歩しながら**測定しています。

| 場面 | WebGL 2 FPS | WebGPU FPS |
|---|---:|---:|
| PAD 01へ接近 | 200.2 | 200.3 |
| 港で駐機 | 200.3 | 200.2 |
| 市街地を速歩 | 200.2 | 199.9 |

全場面のp95とp99は約5.1ms。WebGPUの速歩中の最大間隔は10ms、GPU timestampは約0.46〜0.59msです。ブラウザの時間量子化を含む短い測定であり、旧版からのFPS向上やAPI間の優劣は断定しません。詳細なフレーム数・ドロー数・三角形数は[測定JSON](validation/settlement-quality.json)に保存しました。

地上と軌道を4往復し、軌道では未使用の地形チャンクが毎回0。地上へ戻ったときのリソース数もWebGL 2はGeometry 246 / Texture 23、WebGPUは247 / 25で4回とも一定でした。長時間・全機種の無リークを証明するものではありませんが、この往復で増え続ける現象はありません。

再実行: `npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e`、`node tests/e2e/settlement-quality.mjs`、`node tests/e2e/settlement-save-recovery.mjs`、`npm run test:surface`（`RENDERER=webgpu`でも実行）、`node tests/e2e/descent-continuity.mjs`、`node tests/e2e/surface-touch.mjs`、`node tests/e2e/pwa.mjs`。起動した配布サーバーの確認は`node tests/e2e/local-release.mjs`です。

モバイルはChromeによる画面・タッチのエミュレーションです。スマホ実機、Safari、別GPU、数時間規模の連続プレイ、星全周の地形境界は今回も未検証です。FPSは明示した条件でのヘッドレスrAF測定であり、モニター上の実表示速度の保証ではありません。
