# v0.6.0 — 見た目と描画性能の仕上げ

宇宙船・敵・基地・探査機・天体・小惑星・星空の見た目を調整し、FPS表示を初期状態で有効にしました。ゲームの操縦・追撃・着陸・探索・保存の流れを維持しています。

## オブジェクト

- **LX-07**: 装甲の留め具、翼の放熱部、着陸脚のシリンダーと接地パッドを追加。静的な部品を既存の材質バッチに含め、機体全体のメッシュ数20を維持。
- **敵機**: 面取りした胴体、後退翼、キャノピー、双発のノズル、砲身、放熱口。装甲244三角形・機械部780三角形を全敵で共有し、各部をInstancedMeshで描画。役割で色と大きさを変えます。ブーストの排気をノズル位置から伸ばすよう修正。
- **撃破と命中**: 固定プールの閃光と火花。最大12エフェクト・120火花に制限し、時間とともに拡大・減光。戦闘中にGeometryやMaterialを生成しません。
- **着陸基地**: 分割されたデッキと外周灯、通路、気密居住区、エアロック、装置室、燃料セル、太陽電池、通信設備。6材質バッチと1基礎バッチ。基礎の長さを天体の半径に合わせ、小さな衛星でも建物を球面の地面まで支えます。
- **WAYFARER-3**: 熱保護ブランケット、圧力容器、曲面アンテナ、給電部、センサー、スラスター、分割された太陽電池。4材質バッチ。接近するとビーコンの光を弱め、構造が見えるようにしました。
- **天体**: 岩石と氷の細部、海岸と山地、自然な雲、細かなガス帯と嵐を起動時にGPUで焼き込みます。強すぎた凹凸表現と、雲の引き伸ばされた筋を調整。恒星のコロナを環状にして光球の模様を残しました。
- **小惑星**: 256pxの共有テクスチャで鉱物粒と凹みを追加。Lowは従来の軽量形状、Medium以上は細分した共有形状。全岩石を1回の描画で処理します。
- **背景**: 星雲の彩度と明るさを抑え、天体と機体の輪郭を見やすくしました。

## FPSと画面

右上にFPS・平均フレーム時間・現在の画質を表示します。フレーム数を実際の経過時間で割って測り、約0.25秒ごとに表示を更新します。描画だけのゼロ時間のtickや、タブ復帰の長い空白は計測に含めません。低いFPSでは色が変わります。設定で表示をOFFにできます。

旧版の設定は一度だけ表示ONに移行し、その後のON/OFFの選択を保存します。新しいセーブ形式への変更はありません。スマホではフレーム時間を省略し、体力・戦闘計器・操作ボタンと重ならない位置に配置。縦画面の目標と速度を左右に並べ、着陸案内にも独立した領域を用意しました。

## 検証

`npm run test:polish` は旧設定の移行、表示切替と再読込み、モデルの描画予算、最小の衛星での基礎、全11天体、着陸時の描画、最大エフェクト、スマホ縦横レイアウトを検証します。性能測定と未検証の環境は [検証レポート](VALIDATION.md) を参照してください。

FPSは端末・画面の更新頻度・画質・ブラウザに依存します。ヘッドレスのフレーム頻度と通常ウィンドウの測定は別のデータに記録します。
