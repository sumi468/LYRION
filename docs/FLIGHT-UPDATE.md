# v0.3.0 操縦・デザイン・音楽の更新

v0.3時点の変更記録です。最新の戦闘・着陸は [v0.4](COMBAT-LANDING.md) を参照してください。現在の船体には着陸脚などを追加し20メッシュです。

ユーザーの要望に合わせ、横移動する操縦を前後の主推力とバンク旋回へ変更しました。A/Dで機首を左右に向け、旋回方向へ最大約41度バンクします。入力を離すと自動バンクは戻り、手動ロールは維持されます。Space/Shiftは機首上下です。

船体はLX-07探査船として再設計。面取りした胴体、分割装甲、後退翼、外側に傾く尾翼、ベル型エンジンノズル、小型姿勢制御スラスター、放熱グリル、識別マーキング、微細な表面仕上げを持ちます。静的部品は材質別に結合し、アニメーション部分を含む17メッシュに抑えています。

UIは同梱したOxaniumとM PLUS 1を使用。日本語・英数字ともロードをブラウザで検査しています。BGMは84 BPMのオリジナル曲で、コード進行・低音・アルペジオ・旋律をWeb Audioで合成します。音源の外部配信は使いません。

## 検証

- 型チェック、本番ビルド、単体27件。
- E2E63項目: 基本14、タッチ16、進行と安定性25、今回の操縦・フォント・BGM8。
- 配布版の起動テスト10項目。
- 30 / 60 / 144Hzで旋回角の差が1e-6 rad未満。Aのみで停止位置から平行移動しないことを確認。
- 1秒左旋回でバンク約39.6度、カメラに対する見かけのバンク約34.1度。入力を離すと水平に戻ること、右旋回も逆方向に傾くことを確認。
- 効果音0でもBGM単独の非ゼロ波形を確認し、約2.4秒で15以上の音を予約。
- 画質切替12回でGeometry 18→18、Texture 15→15。WebGL喪失・復帰後も描画。
