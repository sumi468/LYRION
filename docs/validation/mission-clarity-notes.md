# ミッション画面・HUDの安定化

## 実画面で再現した表示不具合

- 再現手順：390×844のタッチ表示で新しい探査を開始し、天体発見通知を表示する。
- 原因：既存の通知配置（左上100px）が、拡張されたミッションHUDの距離・操作欄と重なった。通知を下へ移動した後も、幅が広いと右の戦闘・回避情報に重なることをスクリーンショットで確認した。
- 修正：通知を左側の専用領域（上242px、幅210px以下）へ配置した。横表示では従来の中央領域を維持する。
- 回帰検証：390×844と800×360で、目標・通知と計器・FPS・戦闘情報・基地操作・操作案内の矩形が交差しないことをE2Eで確認する。スクリーンショット用の通知だけを保持し、撮影待ちの間に消えないようにした。

未受注で接岸した船からEVAを開始すると、動的な帰還案内の下に汎用の「Tで接岸」が残る不整合も実画面で確認した。原因は静的な任務ヒントを状態に関係なく表示していたこと。動的な操作案内がある場合はそちらを優先し、汎用ヒントを非表示にした。動的案内がない従来の探査目標に切り替えると、元のヒントを再表示する。E2Eでは「Yで機内へ帰還」の表示、矛盾するヒントの非表示、従来ヒントの再表示を確認した。

## 画面設計と案内の改善

- 六つの遠征の全文を繰り返す画面を、短い一覧と選択中の一つの説明・達成項目に整理した。任務名の選択だけでは受注・進行状態を変更しない。
- 詳細には物語、現在の目標、目的地、達成数、報酬、クリア状況を表示する。受注できない場合は前提任務や接岸の必要性を各ボタンの下に表示する。
- LYRION PRIMEを母星、ASTERIONを任務・補給・報告の基地として案内し、受注から報告までの五段階を表示する。
- EVA中の基地操作にはLX-07への帰還・再搭乗が先に必要であると表示し、戻る操作も「船外活動へ戻る」と表記する。
- HUDには任務コード、現在の目標、その任務内の達成数、目的地、実際の距離、現在の状態で使える操作を表示する。従来の探査目標への切替も維持する。
- モバイルでは、従来非表示だった目標の達成数を常時表示する。短い操作案内と距離を優先し、機体計器やタッチ操作と領域を分ける。
- 完了記録があり詳細な目標フラグのない過去セーブでも、達成数とチェックリストを完了として一貫して表示する。セーブ形式は変更しない。
