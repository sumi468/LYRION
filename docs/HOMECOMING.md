# v0.7 — HOMECOMING & DEEP SPACE EXPEDITION

## 1. 実装内容

既存のゲームへ母星 **LYRION PRIME**（正式ID `lyrion-prime`）、公転する軌道基地 **ASTERION STATION**、ドッキング、3D宇宙飛行士の船外活動、科学調査、6つの遠征を追加しました。TypeScript / Three.js / Vite を継続使用し、新しい依存パッケージや外部画像・音声は追加していません。

PRIMEはタラッサの衛星軌道とハルシオン小惑星帯の間を公転します。海・大陸・雲・大気・夜側の居住灯を描画します。ASTERIONは母星中心から720u、周期1800秒で公転し、惑星と反対側に接岸口を向けます。加圧モジュール、接続部、太陽電池、放熱板、トラス、通信アンテナ、保守設備を材質ごとに結合しています。

## 2. 遊びの流れ

| 遠征 | 内容 | 報告報酬 |
|---|---|---:|
| 最初の出発 | ブリーフィング→出航→航法地点→速度安定→接岸→報告 | 30 DATA |
| 軌道上の点検 | 接岸→船外活動→保守パネル→環境センサー→再搭乗→報告 | 40 DATA |
| 通信システムの修復 | 診断→増幅器の修理→通信検証→帰還・報告 | 50 DATA |
| 初の衛星探査 | 月へ移動→スキャン→母星へ帰還・報告（着陸は任意） | 70 DATA |
| 失われた信号 | WAYFARER-3へ接近→船外でレコーダー・記憶素子を回収→報告 | 90 DATA |
| 未知の領域 | 遠方の観測ブイ→異常信号の観測→旧遠征の証拠を回収→帰還・報告 | 120 DATA |

調査にも個別の研究報酬があります。11か所の調査地点には任意の軌道デブリ・観測衛星も含まれます。調査中は範囲内に留まる必要があり、離れると作業を中断します。修理前の診断などの前提条件があります。調査済みの成果は後から受注した遠征でも認められ、同じ報酬は再取得できません。遠征の受注・成果報告は基地に接岸して明示的に行います。

旧11天体の図鑑と8ミッションは引き続き進行できます。母星のスキャンは図鑑完成条件へ追加していません。遠征ボードの表示切替で従来の目標を追跡できます。

飛行中のEは従来どおりロールです。船外活動では機体の推進・武器入力が働きません。接岸中も推進を無効にし、モード切替・一時停止で押しっぱなし入力を解除します。交戦中は船外へ出られません。基地周辺と船外活動は戦闘から保護されます。

## 5. 遠征の始め方

新規ゲームは母星と基地が正面に見える軌道から始まります。T / DOCKで接岸してからB / MISSION CONTROLで「最初の出発」を読み、**受注して追跡**を選択し、操縦へ戻ります。青い誘導マーカーを追ってください。航法地点は基地の外側にあるので、基地から離れる方向へ旋回します。Xで相対速度を落とし、2秒間安定すると帰還目標へ切り替わります。

旧セーブは元の場所から再開します。メインメニューまたは一時停止からMISSION CONTROLを開き、6つの遠征を確認できます。「基地へ誘導」でASTERIONを選択し、帰還・接岸して新しい遠征を受注します。図鑑や従来のミッションがリセットされることはありません。

## 6. 接岸と船外活動

接岸は基地の惑星と反対側へ回り込み、誘導灯から150u以内・相対速度18u/s以下でT / DOCK。自動で接近・姿勢合わせ・係留を行います。係留後は基地ボードで修理・補給・遠征報告が可能です。離脱もT / DOCKで行い、通路を抜けてから手動操縦へ戻ります。

船外へ出るときは、基地や調査対象との相対速度10u/s以下でH / EVA。見える宇宙服を独立操作できます。設備の3.6u以内でE / 調査を押し、表示された進捗が満了するまで留まってください。アンテナの修理後は状態灯も変わります。

ハッチから4u以内でH / 搭乗。Y / 帰還は基地の外殻を避けてハッチへ誘導します。宇宙服の酸素は360秒、活動範囲は船から600u。酸素切れ・範囲逸脱では安全回収します。調査結果と報酬は失われません。

## 7. 保存互換

同じ`lyrion.save.v1`キーを継続使用し、保存内容のバージョンを**4**へ更新しました。未公開ローカルv3の`prime`を`lyrion-prime`へ移行し、既存の調査・遠征進行・戦闘記録を維持します。v1/v2から機体位置・向き・速度、スキャン、探知、強化、DATA、旧ミッション、着陸記録を引き継ぎます。旧セーブでは新遠征の追跡を自動で開始しません。

遠征の受注・達成・報告、調査記録、係留状態を保存します。船外で保存した場合は、調査結果を保持して保存時のLX-07へ機内復帰します。宇宙飛行士の途中位置を正確に再現する方式ではありません。未知IDや不正な数値は検証し、安全な既定値へ戻します。

## 8. 検証結果

最新の実行結果と測定値は[Homecoming検証レポート](HOMECOMING-VALIDATION.md)を参照してください。新しいE2Eは6遠征の受注・作業・帰還・報告を最後まで実行します。長距離移動と検査地点への配置は既存の決定的デバッグ方式で短縮し、スキャン・着陸・調査・報酬は通常APIで進めます。セーブの成果や報酬を直接書き換える検証ではありません。

## 9. 性能測定

変更前のv0.6を同じPCで再測定した記録を`docs/validation/homecoming-baseline.json`へ保存しました。通常探査・母星軌道・基地・船外活動・戦闘・低画質のモバイル寸法の6場面を`homecoming-gpu.json`へ記録します。GPUクエリの描画時間と、ブラウザのrAF頻度を分けます。ヘッドレスのrAF/sを実モニターの表示FPSとして扱いません。

## 10. 制限と今後

- PRIMEは軌道から観測する母星です。全面の地表歩行、都市への着陸、基地内部の徒歩探索は実装していません。既存の岩石・氷天体への着陸は継続できます。
- 物理はゲーム用の尺度、公転基準系と簡易衝突です。宇宙船の無操作時の船外待機や緊急回収にはゲーム上の支援があります。
- 回収品は調査アーカイブへ記録します。手で物体を持つ操作や自由な工作はありません。
- 別GPU、スマホ実機、iOS Safari、Firefox、数時間の連続プレイ、音楽の人間による聴感確認は未検証です。
- 最新仕様に従い、**本番への自動デプロイはしていません**。公開中の旧版とは区別してください。

今回の追加修正と公開版の差分は[Critical Implementation Fix](CRITICAL-FIX.md)を参照してください。
