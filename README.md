# LYRION — Beyond the Stars · v0.6.0

**[ブラウザで遊ぶ](https://lyrion-lilac.vercel.app)** · [GitHub](https://github.com/sumi468/LYRION)

架空のリリオン星系を探検するブラウザ3Dゲーム。11天体をスキャンし、探査データで船を強化して、8段階のミッションを完成させます。TypeScript / Three.js / Vite。外部の画像・音声配信には依存しません。

## すぐ遊ぶ（Windows）

1. ZIPを任意のフォルダーに展開する。
2. **`START.cmd` をダブルクリック**する。ブラウザが開きます。
3. 「新しい探査を開始」を選ぶ。終了時はサーバーの画面で Ctrl+C。

Node.js **22.12以降**が必要です。この配布物には `dist/` を含めているので、遊ぶだけなら `npm install` は不要です。最初のロードではGPUで惑星と星空を生成します。進捗表示が終わるまでお待ちください。

`START.cmd` は `scripts/serve.mjs` を使い、`http://127.0.0.1:4173` で配信します。ポートが使用中なら次の空きポートを試します。ブラウザが自動で開かない場合は、画面に出るURLを開いてください。`dist/index.html` の直接ダブルクリックでは起動しません。

Mac / Linux では `node scripts/serve.mjs` を実行し、表示されたURLを開きます（これらのOSでの実機検証は未実施）。

操作と数値は [追撃戦の説明](docs/DOGFIGHT.md)、着陸を含む基本操作は [戦闘と着陸](docs/COMBAT-LANDING.md) を参照してください。

## v0.3.0 — 操縦・船体・音楽の更新

- A/Dと左右キーをバンク旋回に変更。横・垂直の平行移動を外し、Space/Shiftは機首の上下操作になりました。前後の主推力と慣性を残し、角速度を滑らかに変化させます。
- 旋回時は約41度まで自動バンクし、入力を離すと戻ります。追尾カメラは傾きを一部だけ追従するため、船体のバンクが見えます。Q/Eの手動ロールも使えます。
- 新しい探査船LX-07: 面取りした一体型船体、装甲パネルと微細な表面仕上げ、後退翼、傾斜尾翼、ベル型ノズル、姿勢制御の小型噴射口。静的部品は材質別に結合しています。
- Oxanium（英数字）とM PLUS 1（日本語）を同梱。ロゴ・HUD・メニュー・設定に使用します。
- 84 BPMのオリジナルBGM: コード、低音、アルペジオ、メロディーを合成。開始操作後に流れ、一時停止と音量設定に対応します。

v0.3の変更は [操縦の更新記録](docs/FLIGHT-UPDATE.md) にあります。

## 開発・再検証

```sh
npm install
npm run dev
npm run typecheck
npm test
npm run build
npm run test:e2e
npm run test:polish
npm run test:gpu
npm run test:soak
npm run test:launcher
```

E2EはPlaywrightを使用します。Windowsではインストール済みChromeがあれば利用し、それ以外は `npx playwright install chromium` でブラウザを取得してください。`BROWSER_CHANNEL=chrome` / `msedge`、`HEADED=1`、`SOFTWARE_GL=1` で切り替えられます。GPU測定と連続飛行テストはソフトウェアGLを検出すると失敗します。

Windows PowerShellで環境変数を設定する例:

```powershell
$env:BROWSER_CHANNEL = 'chrome'
npm run test:gpu
```

`SOAK_SECONDS` は連続飛行の秒数（既定120秒）。スクリーンショットは `docs/screenshots/`、測定データは `docs/validation/` に出力します。`?debug` を付けたときだけ `window.__lyrion` を公開します。`texturesReady` で画質変更の再ベイク完了を待てます。通常の配布URLでは公開しません。

## 構成・設計

- `src/core/`: 状態遷移とゲーム統括、イベント、HUD用スナップショット。
- `src/data/`: 天体・ミッション・強化定義。進行可能性を単体テストで確認。
- `src/physics/`, `src/systems/`: 軌道、飛行、衝突、スキャン、報酬、セーブ、設定。
- `src/render/`: GPUテクスチャ生成、天体、大気、雲、リング、LOD、画質制御。
- `src/audio/`: Web Audioによる合成音・BGM。
- `src/input/`, `src/ui/`: キーボード・マウス・タッチ入力とDOM画面。
- `scripts/serve.mjs`: 依存パッケージを使わない配布版サーバー。

Floating Originで描画座標を原点相対に保ち、天体位置は時刻から計算します。小惑星帯はInstancedMesh、惑星は距離LOD。画質は `QUALITY_LADDER` の6段階に集約され、固定設定はL1 / L3 / L5、Autoは実測フレーム時間で調整します。一度下げた段を上限にして頻繁な往復を抑えます。

セーブ・設定はブラウザのlocalStorage（`lyrion.save.v1`, `lyrion.settings.v1`）。保存キーを維持してセーブ内容をv2へ拡張し、v1のデータを引き継ぎます。旧設定には新項目を補完します。URLのホスト・ポートやブラウザを変えると保存場所は別になります。破損データや保存容量超過への耐性をテストしています。

開発時の作業規則は [AGENTS.md](AGENTS.md)、旧版の引き継ぎ資料は [履歴](docs/history-v0.1.0.md) にあります。
